PAC-MAN Reimplementation
A simple reimplementation of the classic PAC-MAN game, featuring both MATLAB and JavaScript/HTML versions.
The MATLAB version focuses on recreating the game logic and mechanics, while the Web version can be played directly in a browser.
Features
·Classic PAC-MAN maze and gameplay
·Four ghost AI
·Power pellets and Frightened mode
·Score and lives system
·Sound effects and background music
·Playable Web version
Controls
·↑ ↓ ← → / WASD — Move
·P — Pause / Resume
·SPACE — Restart
·ESC — Exit

吃豆人复现
一个简单的经典吃豆人复现项目，包含 MATLAB 与 JavaScript/HTML 两个版本。
MATLAB 版本主要用于复现游戏的核心逻辑与机制，Web 版本则可以直接在浏览器中游玩。
功能
·经典吃豆人迷宫与游戏机制
·四只鬼魂 AI
·能量豆与 Frightened 模式
·分数与生命系统
·音效与背景音乐
·可直接游玩的网页版
操作
·↑ ↓ ← → / WASD — 移动
·P — 暂停 / 继续
·SPACE — 重新开始
·ESC — 退出
